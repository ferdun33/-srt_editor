📝 Описание
Редактор субтитров SRT – это консольная утилита для работы с файлами субтитров в формате SubRip (.srt). Программа позволяет загружать, просматривать, редактировать, синхронизировать и сохранять субтитры, предоставляя набор инструментов для профессиональной работы с видео-контентом.

Возможности:

✅ Загрузка и сохранение SRT-файлов (UTF-8)

✅ Просмотр списка субтитров с номерами, таймингами и текстом

✅ Добавление, удаление, вставка субтитров

✅ Редактирование текста и времени (начало/конец)

✅ Сдвиг всех субтитров на заданное количество миллисекунд (синхронизация)

✅ Автоматическая перенумерация после изменений

✅ Проверка корректности: непересекающиеся тайминги, порядок, формат

✅ Экспорт в формате SRT с корректным форматированием

✅ Интерактивный и командный режимы

✅ Пакетная обработка (опционально)

Проект содержит 8 полноценных реализаций на разных языках программирования, демонстрирующих работу с текстовыми файлами, временными метками и пользовательским вводом.

🎯 Сценарии использования
Синхронизация субтитров – если видео начинается с задержкой, можно сдвинуть все тайминги на нужное значение.

Исправление ошибок – изменение текста или времени отдельных субтитров.

Объединение субтитров – вставка субтитров из другого файла.

Проверка качества – выявление пересечений, пропусков, неправильного порядка.

📦 Установка и запуск
Каждая реализация находится в отдельной папке. Для запуска требуется соответствующий компилятор/интерпретатор и зависимости.

Язык	Файл	Зависимости	Команда запуска
Python	srt_editor.py	нет (стандартная библиотека)	python3 srt_editor.py [файл.srt]
Go	srt_editor.go	нет	go run srt_editor.go [файл.srt]
Rust	srt_editor.rs	regex (опционально)	cargo run -- [файл.srt]
C++	srt_editor.cpp	нет (STL)	g++ -std=c++17 -o srt_editor srt_editor.cpp && ./srt_editor [файл.srt]
Java	SrtEditor.java	нет (Java 8+)	javac SrtEditor.java && java SrtEditor [файл.srt]
C#	srt_editor.cs	нет (.NET Core)	dotnet run [файл.srt]
Ruby	srt_editor.rb	нет	ruby srt_editor.rb [файл.srt]
Node.js	srt_editor.js	нет	node srt_editor.js [файл.srt]

🎮 Использование
text
srt_editor [файл.srt]              # Интерактивный режим
srt_editor --shift 1000 файл.srt   # Сдвинуть все субтитры на 1000 мс вперёд
srt_editor --check файл.srt        # Проверить корректность
srt_editor --output new.srt файл.srt # Сохранить в другой файл (после редактирования)
В интерактивном режиме доступны команды:

list – показать все субтитры

show <номер> – показать конкретный субтитр

add – добавить субтитр (ввод времени и текста)

edit <номер> – редактировать субтитр

delete <номер> – удалить субтитр

shift <мс> – сдвинуть все субтитры

renumber – перенумеровать (восстановить порядок)

validate – проверить корректность

save – сохранить изменения

quit – выход
